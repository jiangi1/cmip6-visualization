Data Source

CMIP6 (Coupled Model Intercomparison Project Phase 6) from NOAA/Google Cloud Public Dataset. The data includes temperature anomaly projections (2015-2100) for SSP1-2.6, SSP2-4.5, and SSP5-8.5 scenarios. Our low scenario data is real CMIP6 data; medium and high scenarios are derived using published warming ratios (1.8× and 3.0× respectively) based on CMIP6 multi-model means.

Data: CMIP6 Climate Model Projections | Built with D3.js | Interactive visualization for climate exploration
